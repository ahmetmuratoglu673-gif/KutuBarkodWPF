# KutuBarkodWPF - Etiket Tasarım Stüdyosu

Barkod ve QR kod etiketleme süreçlerini yönetmek ve otomatize etmek amacıyla C# ve WPF kullanılarak geliştirilmiş masaüstü uygulamasıdır.

## 🚀 Özellikler
* **Dinamik Veri İşleme:** Excel üzerinden alınan ham verilerin kod arka planında dinamik olarak etiket alanlarına aktarılması.
* **Esnek Tasarım Alanı:** Sürükle-bırak (drag-and-drop) mimarisi ile şekillendirilebilen özelleştirilebilir canvas yapısı.
* **PDF Çıktısı:** PdfSharp altyapısıyla oluşturulan şablonların operasyonel verimliliğe odaklanarak toplu PDF formatında dışa aktarılması.
* **Karekod ve Barkod Üretimi:** Verilere dayalı hızlı ve güvenilir etiket oluşturma modülü.

## 🛠️ Kullanılan Teknolojiler
C# | WPF | XAML | PdfSharp
